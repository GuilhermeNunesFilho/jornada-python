# 🤖 Projeto de Automação de Processos

Este projeto foi desenvolvido com o objetivo de automatizar tarefas manuais e repetitivas utilizando a linguagem Python, demonstrando como a tecnologia pode otimizar o tempo e reduzir erros operacionais no dia a dia de uma empresa.

---

## 🎯 O Problema Resolvido

Processos manuais de digitação, movimentação de arquivos ou preenchimento de sistemas demandam muito tempo e estão sujeitos a falhas humanas. Esta ferramenta substitui a interação manual por uma execução totalmente automatizada, precisa e veloz.

---

## 🛠️ Tecnologias e Ferramentas

*   **Linguagem:** Python 3
*   **Principais Bibliotecas:** 
    *   `PyAutoGUI` (para automação e controle de mouse e teclado)
    *   `Time` (para gerenciamento de pausas e sincronização do sistema)

---

## 🚀 Como Funciona (Funcionalidades)

1.  **Interação com a Interface:** O script simula cliques do mouse e digitação de textos em campos específicos.
2.  **Fluxo Inteligente:** Possui pausas estratégicas para esperar o carregamento de telas e sistemas externos.
3.  **Execução em Lote:** Capacidade de repetir o processo de forma contínua para grandes volumes de dados.

---

## 📋 Pré-requisitos para Execução

Para rodar este script na sua máquina, você precisará ter o Python instalado e a seguinte biblioteca:

```bash
pip install pyautogui
```
