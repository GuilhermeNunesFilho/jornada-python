# 🐍 Jornada Python: Do Básico à Automação e Inteligência Artificial

Bem-vindo ao meu repositório de evolução em Python! Este espaço foi criado para documentar minha jornada de aprendizado, centralizando desde conceitos fundamentais até soluções completas de automação e modelagem de dados.

O objetivo principal é demonstrar a aplicação prática da programação para resolver problemas reais de negócios e otimização de processos.

---

## 🛠️ Portfólio de Projetos e Estudos

Abaixo estão os principais projetos desenvolvidos nesta jornada, organizados por nível de complexidade e área de atuação:

### 🤖 Automação de Processos & Dados
* **[Projeto Automação](./Projeto_Automacao):** Script desenvolvido para otimizar tarefas repetitivas, reduzindo o tempo de execução e eliminando erros manuais.
* **[Automação de Planilhas](./04-automacao-planilhas):** Manipulação, extração e consolidação de dados em arquivos Excel utilizando Python para geração de relatórios eficientes.

### 🧠 Data Science & Machine Learning
* **[Machine Learning](./Machine_Learning):** Modelos preditivos e análise de dados focados em extrair insights e apoiar tomadas de decisão.

### 💻 Aplicações Práticas (Interface Gráfica)
* **[Calculadora com Interface](./Python_Inicial/Calculadora_Com_Interface.ipynb):** Aplicação desktop desenvolvida para praticar lógica de programação e design de interface de usuário (UI).

### 📚 Fundamentos da Linguagem
* **[Python Inicial](./Python_Inicial):** Minha base sólida na linguagem, contendo a prática de estruturas de repetição, condicionais, manipulação de textos e criação de funções modulares.

---
