# 🧮 Aplicação Prática: Calculadora com Interface Gráfica

Este projeto consiste em uma calculadora desktop funcional desenvolvida em Python. O objetivo principal foi consolidar conceitos de lógica de programação e explorar o desenvolvimento de interfaces de usuário (UI).

---

## 🎯 O Problema Resolvido

Aprender programação exige ir além das telas pretas do terminal. Este projeto resolve o desafio de criar uma aplicação interativa e amigável para o usuário final, simulando o desenvolvimento de softwares comerciais reais do mundo desktop.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python 3
* **Interface Gráfica:** `Tkinter` (ou a biblioteca correspondente utilizada no seu código)
* **Ambiente:** Jupyter Notebook (`.ipynb`)

---

## 🚀 Funcionalidades

* **Operações Básicas:** Adição, subtração, multiplicação e divisão.
* **Interface Responsiva:** Botões clicáveis e campo de exibição de texto em tempo real.
* **Tratamento de Erros:** Prevenção de falhas comuns, como a tentativa de divisão por zero.

---

## 📸 Como Visualizar e Executar

Como este projeto está em formato de Jupyter Notebook (`.ipynb`), você pode clicar diretamente no arquivo `Calculadora_Com_Interface.ipynb` aqui no GitHub para visualizar o código e a estrutura do projeto de forma interativa.
